- **Issa:** Consulting firms (McKinsey, LEK, EY, Deloitte) + investment banks (Leerink, Jefferies) + follow-ups from Week 1-2

- **Data hooks:** #10 (Israel model), #11 (TL1A reset), #13 (CAR-T economics)
- **LinkedIn:** Post hooks #10, #14, #17

## Tracking & Metrics

### Weekly Check (Friday, intern logs)
1. Update `backlink_outreach` table with all contacts, statuses, and follow-up dates
2. Count: emails sent, replies received, backlinks acquired
3. Screenshot GSC indexed page count (from gsc-sync cron data)

### Monthly Review (Issa + intern, 30 min)
1. Which data hooks got the most replies?
2. Which audience (journalist/VC/BD/consultant) converted best?
3. Any backlinks acquired? From which outreach?
4. LinkedIn post performance — which hooks drove most engagement?
5. Adjust next month's hook rotation based on what worked
