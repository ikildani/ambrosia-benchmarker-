## PRODUCTION NOTES

### Screen Recording Guidelines
1. **Browser:** Use Arc or Chrome with minimal UI
2. **Resolution:** Record at 4K, export at 1080p for crisp text
3. **Cursor:** Use custom cursor (larger, with subtle trail)
4. **Scrolling:** Smooth, deliberate (use scroll smoothing tool)
5. **Clicks:** Add subtle "press" animation in post

### Caption Styling
```css
/* Primary Headlines */
font-family: 'Inter', sans-serif;
font-weight: 700;
font-size: 48px;
color: #FFFFFF;
text-shadow: 0 4px 20px rgba(0,0,0,0.5);

/* Secondary Text */
font-weight: 400;
font-size: 32px;
color: #94A3B8;

/* Emphasis */
color: #14B8A6; /* Teal accent */
```

### Transition Library
- **Scene changes:** 0.5s crossfade
- **Text reveals:** 0.3s fade-up with slight blur
- **Number counters:** Smooth easing (ease-out-expo)
- **UI interactions:** Match app's actual transitions

### Motion Principles
1. **Intentional:** Every movement has purpose
2. **Smooth:** 60fps, no jarring cuts
3. **Breathing room:** Let key moments land (1-2 sec holds)
4. **Rhythm:** Build tempo toward CTA

## TOOLS RECOMMENDED

### Recording
- **Screen:** OBS Studio or ScreenFlow
- **Browser:** Arc (for clean UI) or Cleanshot X

### Editing
- **Professional:** After Effects, Final Cut Pro, DaVinci Resolve
- **Quick:** Descript, Kapwing, or Canva Video

### Motion Graphics
- **Logo animation:** After Effects or Jitter
- **Text animations:** Built-in editor presets or CapCut

### Export Settings
- **Codec:** H.264 or H.265
- **Bitrate:** 20-30 Mbps for quality
- **Frame rate:** 30fps (60fps for UI recordings)
