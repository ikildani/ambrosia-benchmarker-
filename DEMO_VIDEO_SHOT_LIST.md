## RECORDING TIPS

### Browser Setup
```
1. Window size: 1920x1080
2. Bookmarks bar: Hidden
3. Extensions: Hidden
4. URL bar: Show only domain (use Arc browser)
5. Dark mode: Enable for cinematic feel
```

### Cursor Movement
```
- Speed: Deliberate, not rushed
- Path: Smooth curves, not jagged lines
- Hover: Always pause 0.5s before clicking
- Tool: Consider Presentify or similar for smooth cursor
```

### Click Timing
```
- Hover → 0.5s pause → Click → 0.5s pause → Next action
- Let UI animations complete before moving
```

### Common Mistakes to Avoid
```
- ❌ Moving cursor too fast
- ❌ Cutting during UI animations
- ❌ Showing loading/error states
- ❌ Notifications appearing
- ❌ Cursor leaving frame abruptly
```
